# 中国广电吉视传媒抽奖系统

## 项目概述

这是一款专为**中国广电吉视传媒**线下市场营销活动开发的纯离线安卓抽奖工具APP。

### 核心特性

- **完全离线运行**：无需服务器、无需联网、不上传任何数据
- **本地加密存储**：所有数据采用SQLCipher加密数据库本地存储
- **防篡改机制**：工作日志全程自动记录，永久不可修改、不可删除
- **权限严格隔离**：员工仅可操作抽奖，管理员拥有完整配置权限
- **政企风格设计**：广电蓝主色调+中国红+金色点缀，稳重正式且喜庆

## 功能模块

### 一、员工端抽奖流程

1. **客户信息录入**
   - 必须填写客户姓名和手机号
   - 手机号格式自动校验
   - 信息不可跳过

2. **重复抽奖拦截**
   - 同一手机号当日仅允许抽奖1次
   - 系统自动检测并拦截重复参与

3. **转盘抽奖**
   - 精美转盘动画效果
   - 根据预设概率随机中奖
   - 结果不可撤销、不可重抽

4. **防误触设计**
   - 抽奖页面无返回按钮
   - 需两次确认才可退出

### 二、管理员后台

**进入方式**：连续点击LOGO 5次 + 输入管理员密码

#### 1. 奖品管理
- 添加、编辑、删除奖品
- 设置每个奖品的中奖概率
- 系统自动校验概率总和必须等于100%
- 支持奖品图片上传

#### 2. 活动设置
- 开启/关闭抽奖活动
- 设置活动有效期（开始/结束日期）
- 设置每日最大抽奖次数
- 修改管理员密码

#### 3. 抽奖记录
- 查看所有抽奖记录
- 按日期筛选查询
- 支持导出Excel/PDF
- 数据归档管理

#### 4. 数据统计
- 自动汇总统计
- 各奖项中奖数量统计
- 中奖率自动计算
- 导出统计报表

### 三、数据安全

1. **加密存储**
   - 采用SQLCipher数据库加密
   - 敏感数据本地加密保存
   - 设备唯一标识绑定

2. **防篡改机制**
   - 工作日志自动记录
   - 员工无法查看、无法删除
   - 归档数据永久不可修改

3. **导出安全**
   - 导出文件自带水印
   - Excel文件设置只读保护
   - PDF文件带数字签名

## 使用说明

### 首次使用

1. **安装APK**
   - 下载并安装 `GuangDianLottery.apk`
   - 授予存储权限（用于导出数据）

2. **管理员初始化**
   - 连续点击LOGO 5次
   - 输入默认密码：`admin123`
   - 立即修改管理员密码

3. **配置奖品**
   - 进入"奖品管理"
   - 添加奖品并设置概率
   - 确保概率总和等于100%

4. **开启活动**
   - 进入"活动设置"
   - 设置活动有效期
   - 开启抽奖开关

### 员工操作

1. 点击"开始抽奖"
2. 输入客户姓名和手机号
3. 点击转盘开始抽奖
4. 截图保存中奖信息

### 数据导出

1. 进入管理员后台
2. 选择"抽奖记录"或"数据统计"
3. 设置筛选日期范围
4. 点击"导出Excel"或"导出PDF"
5. 分享或保存导出文件

## 安全说明

### 数据保护
- 所有数据本地存储，不上传云端
- 数据库采用256位AES加密
- 敏感字段额外加密处理

### 权限控制
- 员工端无配置权限
- 管理员操作需密码验证
- 隐藏入口防止误操作

### 审计追踪
- 完整记录所有操作
- 包含时间戳、设备ID、操作人
- 日志不可删除、不可修改

---

## 注意事项

1. **数据备份**
   - 定期导出数据备份
   - 重要活动前备份数据库

2. **设备安全**
   - 仅限授权设备使用
   - 妥善保管管理员密码
   - 离职员工及时修改密码

3. **概率设置**
   - 所有奖品概率总和必须等于100%
   - 建议预留一定概率给"谢谢参与"
   - 大奖概率不宜过高

4. **活动期限**
   - 合理设置活动有效期
   - 及时关闭过期活动
   - 避免纠纷
